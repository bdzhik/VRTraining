# VRTraining

VR-тренажёр безопасной подготовки промышленного конвейера к обслуживанию, разработанный на Unity 6, URP, OpenXR и XR Interaction Toolkit. Сценарий хранится в `ScenarioDefinition` и состоит из независимых групп, шагов и ожидаемых действий. Чистая C#-машина состояний `ScenarioSession` проверяет правильность и последовательность действий, фиксирует статусы шагов и не зависит от Unity, XR, UI или звука.

Источники взаимодействий преобразуют события XR, триггеров и UI в единый `TrainingAction` и передают их через локальную событийную шину без static-состояния и DI-контейнеров. Отдельные presenter-компоненты отвечают за HUD, подсветку Outline, звуковую обратную связь, результаты и визуальное состояние конвейера, поэтому сценарные правила не связаны с конкретными объектами сцены и могут расширяться через ScriptableObject.
